# ChatGPT Work 삽화 작업 지침

ChatGPT 데스크톱 앱의 **Work**가 이 프로젝트에서 도감 삽화를 그릴 때 따르는 절차다.
API 키 없이 앱에 들어 있는 이미지 생성(`$imagegen`, gpt-image-2)으로 그리고, 그림은 요금제 사용량에서 나간다.

목표는 **한 번에 실제 새와 같게** 그리는 것이다. 다시 그리기는 요금제 사용량을 쓰므로, 아래 1–2단계의 준비를 꼼꼼히 해서
처음 그림이 맞게 나오게 한다. 다시 그리기는 3단계의 기준에 걸릴 때만 한다.

## 할 일

1. 프로젝트 맨 위에서 실행한다.
   ```
   uv run tools/illustrate.py queue --limit 4
   ```
   아직 그림이 없는 작업이 JSON 배열로 나온다(흔한 종부터 드문 종 순: 새와 생명의 터 2022 목록의 해마다 찾아오는 개체 수 범위, 같으면 도판 번호 순).
   항목마다 `id`, `ko`(국명), `kind`, `size`, `orientation`, `save_to`, `refs`, `photo_refs`, `prompt` 가 있다.
   그림 재료가 '조사 중'인 종은 목록에 나오지 않는다(건너뛴 수는 표준 오류로 한 줄 나온다).
2. **그리기 전에** 항목마다:
   - `photo_refs` 의 사진(그 종의 실제 사진, 대부분 한국에서 찍은 것, 최대 4장)을 모두 열어 본다.
     새가 크고 또렷하게 보이는 사진 **2장**을 고른다. 새가 작거나 흐리거나 가려진 사진, 소리 그림(스펙트로그램),
     죽은 새, 화면을 찍은 사진, 이름과 달리 다른 종으로 보이는 사진(관찰자의 오동정)은 쓰지 않는다.
     쓸 만한 사진이 1장뿐이면 그 1장만 붙인다.
   - 고른 사진에서 머리 모양(댕기가 있는지), 부리 길이와 모양, 눈 색, 다리 길이와 색, 깃의 색과 무늬를 확인한다.
     이것이 `prompt` 의 글과 함께 '정답'이 된다.
   - `photo_refs` 가 비어 있으면(사진을 받지 못함) 인터넷에서 그 종(`prompt` 첫머리의 영어 이름과 학명)의 사진을
     한국이나 동아시아에서 찍은 것으로 2장 찾아 같은 방법으로 쓴다(iNaturalist, Wikimedia Commons 등).
3. 항목마다 한 장씩 그린다.
   - `$imagegen` 에 `prompt` 를 **고치지 말고 그대로** 넣고, 고른 사진 2장을 **함께 붙인다**(실제 생김새 참고용).
     `refs` 에 파일이 있으면 그것도 붙인다(화풍 참고용). 방향과 크기는 `orientation`·`size` 를 따른다
     (`scene` = 가로 1536×1024, `plate` = 세로 1024×1536).
   - 결과를 `save_to` 경로(예: `art/inbox/aix-galericulata.png`, 동정 도해는 `art/inbox/aix-galericulata.id.png`)에 PNG로 저장한다.
   - 그림을 고른 사진과 나란히 놓고 살펴본다. 아래에 **해당할 때만** 한 번 다시 그린다.
     기준은 '한눈에 보이는 큰 잘못'이다. 홍채 빛깔이 조금 다르다, 댕기가 약간 과장됐다, 색조가 조금 진하다 같은 작은 차이는 다시 그리지 않는다.
     - 실제 사진과 생김새가 크게 다르다: 없는 댕기·장식깃이 뚜렷하다, 부리 길이나 굽은 정도가 다른 종처럼 보인다, 머리·몸의 색과 무늬가 다른 종이나 다른 철처럼 보인다, 몸 비율이 어긋난다.
     - 프롬프트의 `Mistakes to avoid` 에 적힌 잘못을 그대로 했다.
     - 글자·숫자·서명·테두리가 들어갔다.
     - 고개가 몸과 반대로 꺾이는 등 자세가 부자연스럽다.
     - `plate` 인데 배경에 풍경이 있거나, 요구한 모습(views) 수가 맞지 않다.

     다시 그릴 때는 무엇이 틀렸는지 한 문장으로 `prompt` 끝에 덧붙인다(예: "The head has no crest; keep the crown feathers flat as in the photographs.").
     다시 그린 것도 어긋나면 저장하지 않고 4단계 보고에 적는다(그 종은 사람이 프롬프트를 고친다).
4. 다 그렸으면 실행한다.
   ```
   uv run tools/illustrate.py import
   ```
   webp로 줄여 `img/` 에 넣고 원본은 `art/raw/` 로 옮긴 뒤 `data/*/book.json` 을 다시 만든다.
5. 마지막에 짧게 보고한다: 그린 종, 다시 그린 종과 이유, 저장하지 않은 종과 이유.

## 하지 말 것

- `data/` 의 종 자료, 코드, `tools/style.toml` 을 고치지 않는다.
- `img/` 의 기존 그림을 지우거나 덮어쓰지 않는다.
- `git commit` · `git push` 하지 않는다. 사람이 검수한 뒤 커밋한다.
- 한 번에 `--limit` 보다 많이 그리지 않는다(요금제 사용량 보호).
- 사진을 그대로 베끼지 않는다(구도·자세·배경은 프롬프트대로). 사진은 생김새를 맞추는 데만 쓴다.
